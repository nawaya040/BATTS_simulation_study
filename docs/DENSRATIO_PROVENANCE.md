# densratio source provenance

`vendor/densratio` is a byte-for-byte copy of the modified densratio 0.2.1
source in the submitted R1 reproducibility package, `code/methods/densratio`.
It includes DESCRIPTION, LICENSE, NAMESPACE, NEWS.md, README.md, R/ and man/.
The original MIT license and attribution are retained. No installed library,
compiled binary or private input data is copied. File hashes and source paths
are recorded in DENSRATIO_SOURCE_MANIFEST.csv.

Version 0.2.1 alone cannot identify these local modifications. The bootstrap
installs this exact source and records its file hashes plus installed package
hashes. A generic CRAN/GitHub installation with the same version is insufficient.
